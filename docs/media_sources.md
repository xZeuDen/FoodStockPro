# Media Sources

FoodStockPro currently uses Bootstrap through a CDN link in the base template.

The project also uses custom CSS written specifically for this project in `static/css/style.css`.

No external images are currently used in the project unless images are later added to `static/images`.

Any future images must be listed here with:

- Filename
- Original URL
- Date accessed
- Short note explaining where the image is used
